# TripMindAI

TripMindAI is my Bachelor's final project, created to explore how Artificial Intelligence can be used to make trip planning easier and more personalized.

The main idea behind the project is to help users plan their trips by using AI to generate useful travel suggestions and assist them throughout the planning process.

## About the Project

TripMindAI was developed as an academic project with a focus on combining traditional web development with AI capabilities.

Through this project, I explored:
- AI integration in a web application
- Building a complete full-stack application
- Working with APIs and external services
- Designing a simple and user-friendly travel planning experience
- Using AI to solve a real-world problem

## Main Goal

The goal of TripMindAI is to demonstrate how AI can assist users in planning their trips more easily, while providing personalized and relevant information based on their needs.
